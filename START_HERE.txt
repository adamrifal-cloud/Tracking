🆘 ERROR SAAT SETUP?

   "Docker not found"
   → Install Docker: https://www.docker.com/products/docker-desktop

   "Container not running"
   → Run: docker-compose up -d

   "Permission denied"
   → Run terminal as Administrator

   "MySQL error"
   → Check: docker logs vendor-service-db
